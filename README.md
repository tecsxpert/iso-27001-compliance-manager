# ISO 27001 Compliance Manager

AI-powered compliance management system built using Spring Boot, H2/PostgreSQL, and Swagger/OpenAPI.

---

##  Features

- Compliance Record Management
- CRUD REST APIs
- File Upload Support
- Swagger/OpenAPI Documentation
- Validation & Exception Handling
- H2 Database Integration
- Pagination Support
- Automated Demo Data Seeder
- Unit & Integration Testing

---

##  Tech Stack

### Backend
- Java 17
- Spring Boot 3
- Spring Data JPA
- H2 Database
- Maven
- Swagger/OpenAPI

### Tools
- IntelliJ IDEA
- Postman
- GitHub
